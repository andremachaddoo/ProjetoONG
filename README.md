# ONG Esperança

Projeto acadêmico desenvolvido para a disciplina de Programação para Interface Web.

O projeto apresenta um site para a ONG Esperança, utilizando HTML, CSS e JavaScript.

## Estrutura do projeto

- `html/` - páginas HTML do projeto
- `css/` - arquivos de estilização
- `js/` - scripts JavaScript e módulos utilizados no projeto
- `imagens/` - imagens utilizadas nas páginas

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Versionamento

O projeto utiliza Git para controle de versão e GitHub como repositório remoto.
